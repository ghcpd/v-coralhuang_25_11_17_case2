## ⚙️ Configuration

Set in your app config:

```python
# Optional: Override msgfmt location
app.config["MSGFMT_PATH"] = "/path/to/msgfmt"

# Optional: Custom translation directory
app.config["BABEL_TRANSLATION_DIRECTORY"] = "/custom/path"
```

## 🆘 Troubleshooting

### Missing gettext locally?
All tests use subprocess mocking - no external msgfmt needed locally.

### Docker build fails?
```bash
docker system prune -a
docker build -f Dockerfile.fix .
```

### Tests fail?
```bash
cd fixes
rm -rf .venv artifacts
./setup.sh
./run_test.sh
```
