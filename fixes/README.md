# Translation CLI Fixes

This folder contains a cross-platform, robust implementation of translation compilation and tests.

Usage (Linux/macOS):

1. ./setup.sh
2. ./run_test.sh

Usage (Windows):
1. fixes\run_test.bat

Docker:
1. ./fixes/run_in_docker.sh

Notes:
- The CLI helper is in `fixes/translate_helper.py` and `fixes/cli.py`.
- Tests are written with pytest and can be run directly.
